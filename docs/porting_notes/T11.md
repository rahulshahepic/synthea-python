# T11 (#11) core concepts (agent: chatgpt)

- All seven Java classes are translated. BMI preserves arithmetic operation order,
  including IEEE-754 zero division; Names preserves each bounded integer draw,
  case-insensitive Spanish selection, fallback to English and Java UTF-16 hash suffixes.
- Race/ethnicity maps are immutable views over JavaHashMap to preserve Java iteration.
  Clinician specialties keep the source order and its default CMS code `01`.
- Biometrics reads the original resource through T05 SimpleYML, retaining Integer-only
  `ints` and Number-to-double `doubles` contracts. Python exceptions represent the
  corresponding JVM cast/null failures.
- Telemedicine's Apache Commons Math 3.6.1 boundary normalizes each probability in
  original order and reuses T07's WELL19937c kernel. The constructor's unseeded Java
  RNG uses clock/identity entropy: sampling before explicit `reseed_random_generator`
  raises RuntimeError, rather than inventing a deterministic seed. Actual Synthea
  TypeOfCare callers always reseed immediately before sampling. The resource-backed
  distributions, arbitrary unnormalized/zero probabilities and long-seed streams
  are covered by the probe.
- ConceptsProbe covers every public method across seven long seeds, both independent
  Names class-initialization flags, 1000 first/last pairs per gender/language combination
  (English, Spanish, uppercase Spanish and fallback), 1000 alternating addresses,
  UTF-16 hashes, every specialty/vital, every biometrics path/numeric array and
  1000 samples per distribution. BMI includes random and IEEE edge cases.
- `Person_double` in `tests/parity/test_concepts.py` inherits only T01's actual
  DefaultRandomNumberGenerator. Names reads only RNG plumbing; real Person construction
  currently reaches T16 CoverageRecord, which depends on later work. Production
  Names retains its real Person API and does not bypass it. These are component
  parity tests, with no fabricated collaborator behavior.
- Upstream ClinicianSpecialtyTest#testSpecialtiesMap and
  TelemedicineConfigTest#testFromJSON are ported in tests/unit/test_concepts.py.
  Helpers/TelemedicineTest covers a separate T07 helper and is outside this task.
- Java String.equalsIgnoreCase is preserved via javacompat (including long s,
  dotted capital I and null Names language fallback); additional probe regressions
  exercise these cases rather than relying on Python lower/casefold.

- T07 exposes only SyncedEnumeratedDistro's person-reseeded single-sample helper,
  not an independently reseedable distribution with getPmf/sample. This boundary
  therefore remains local while reusing the T07 WELL kernel without duplication.
- Commons Math 3.6.1 uses Arrays.binarySearch followed by a strict inequality:
  a draw exactly equal to any cumulative boundary falls back to the last value.
  The Java probe overrides nextDouble at boundary/adjacent values; the matching
  Boundary_rng_double supplies only those RNG inputs in component tests. This
  intentionally preserves the pinned library's quirk rather than bisect_right.
