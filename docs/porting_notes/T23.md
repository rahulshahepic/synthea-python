# T23 (#23) Chronic modules and risk calculators (agent: chatgpt)

- Ports ASCVD, Framingham, CardiovascularDiseaseModule, QualityOfLifeModule and
  WeightLossModule. Each engine module retains its real superclass constructor,
  name, identity clone and declared two-argument process overload.
- The component fixture doubles only Java Module's empty no-argument constructor
  while T19 remains unmerged. It automatically stops installing that double once
  T19 is implemented, so the same 50 adult scenarios then run with real engine
  constructors. No calculator, record, claim, coverage, growth or RNG behavior
  is doubled. T20/T21 dependencies remain required before review.
- ChronicModulesProbe runs all three module behaviors for 50 seeded adults,
  age 20 through 62, weekly across 42 years. Both cardiovascular calculation
  modes are exercised. Records carry diabetes, asthma and ADD with differing
  condition stops; 17 scenarios also have a real loss-of-care record. The
  canonical output includes all record/claim fields, all attributes/vitals,
  RNG counts, year-by-year history and explicit integer-year map insertion order.
- Direct risks cover 2,400 varied inputs (ages 15 through 100), five calculators
  and both per-timestep and ten-year modes. Java integer quotients truncate
  towards zero; negative bucket numerators are deliberately preserved. Stroke
  ranges use inclusive ends (a boundary belongs to the earlier segment).
  Presence of atrial_fibrillation is distinct from a true value.
- ASCVD uses the shared fdlibm log and OpenJDK Math.pow/Math.exp compatibility
  routines, preserving multiplication and summation order. No tolerance is used.
- QALY/DALY/QOLS use insertion-ordered Python maps with integer years, matching
  LinkedHashMap<Integer,Double>. The covered-care fraction in Java divides two
  integers before widening; mixed covered/uncovered care therefore selects 0,
  not a floating-point fraction. This bug and the condition start comparison
  are reproduced. Disability weights load the actual resource CSV.
- Weight-loss forced triggers still consume the adherence/maintenance RNG draws
  before overriding their results. First-year/five-year bounds are inclusive.
  Pediatric regression retains the integer year count, five-year divisor,
  tail-based scheduling and cutoff at 240 months.
- An additional 250 pediatric scenarios compare complete trajectories after
  adjustment (including repeated adjustment), maintenance, regression, adult
  transition and process. Original upstream pediatric-regression/transition
  examples have dedicated Java outputs for exact comparison: their published
  approximate expected values are not the exact Java results. Other upstream
  assertions are ported, with exact arithmetic where possible and original
  range assertions for the quality-of-life examples. No scenarios are skipped.
- Own canonical claim encoder extends T08 and is fixture-scoped. External
  collaborator attributes use the existing canonical Person renderer.

- Merge follow-up: reviewer answer on PR #75 (comment 6714329896) permits
  moving Person's QualityOfLifeModule import into get_qalys/get_dalys/
  get_qols_for_year only. This breaks the new Person → QOL → Module → State →
  Logic → Person cycle while keeping real inheritance and unchanged calculations.
