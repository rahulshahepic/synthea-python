# T04 (#3) Port skeleton (agent: chatgpt)

- This task ports declarations and static data only. Constructors and methods raise
  `NotImplementedError` with their Java class, method, and implementing task ID. Runtime
  configuration reads, resource loading, caches, and service/singleton construction remain
  typed static declarations: initializing them would invoke another task's stub or implement
  behavior outside T04. Their owning implementation tasks provide initialization.
- Every method is attached to its declaring Java class (including package-private methods),
  has explicit typed parameters and return type, and keeps static dispatch. Java overloads
  collapse by parameter position into unions and optional trailing parameters. The docstring
  lists the Java overloads. Generic classes/methods use Python 3.12 type parameters.
- Nested classes are defined beside their parents, as allowed by the porting guide, with
  runtime aliases preserving the Java namespaces. Same-module inheritance is retained.
  Cross-module inheritance is deferred to the implementing tasks to avoid import cycles;
  in particular Person does not yet inherit RandomNumberGenerator (T09 owns that change).
  References to T01–T03's types appear only under TYPE_CHECKING.
- Java interface declarations use typing.Protocol. Named Protocol boundaries under
  TYPE_CHECKING stand for external Java library types outside the mapped Python port.
  Object maps to object; decimal amounts use Decimal, UUIDs use UUID, and collection element
  types remain explicit. Generic parameters retain their names rather than becoming Any.
- Java State declares both a field and a method named transition. Its field is _transition
  so it cannot mask the method. The same rule handles other field/method name collisions.
- Java Logic.True and Logic.False use TrueLogic and FalseLogic plus aliases, because Python
  reserves those identifiers. Their runtime class names preserve the Java names for the
  structure checker. C19VaccineAgeDistributions.in uses in_ with an attribute alias.
- Enum member names are preserved. EncounterType and ReactionSeverity constructor data
  live in ENUM_CONSTRUCTOR_ARGUMENTS. VitalSign annotation text lives in
  VITAL_SIGN_DISPLAY_NAMES. Enum behavior remains stubbed; constructing enum constants is
  normal Enum machinery rather than invoking a pending behavioral constructor.
- Clinical Code constants are assembled as static data via object.__new__ and field
  assignments: calling the deliberately unimplemented Code constructor would break imports.
  Unmodifiable Java data maps use MappingProxyType. Claim.ZERO_CENTS retains scale two.
- SkeletonProbe reflects every mapped T04 class, including member classes, without running
  their methods. API goldens check direct declaration ownership, static dispatch, and every
  overload's arity. A separate data golden checks all static fields in ten data classes,
  enum constructor data, and serialized VitalSign labels. Goldens are generated by Java;
  none are committed or hand-authored. Behavioral upstream JUnit suites belong to the
  implementation tasks, not T04's deliberately unimplemented methods.
- Local JDK is 17 and Gradle wrapper download is unavailable in this environment. Per
  AGENTS.md's no-JDK rule, JDK 21 golden generation and required parity run execute in CI.
