# T24 (#24) COVID-19 immunization modules (agent: muse)

- Double-load quirk, reproduced: in Java, constructing a
  `C19ImmunizationModule` triggers `Module.loadModules()`, which itself
  instantiates the core C19 module, so `C19VaccineAgeDistributions.initialize()`
  and `C19Vaccine.initialize()` run twice for the first construction (once
  for the registry's instance, once for the explicit one). Because
  `loadRawDistribution()` *appends* to the static `rawDistributions` lists,
  the distributions are built from duplicated rows (for Ages_12-15_yrs the
  post-May-10 filter is applied twice: 273 raw rows -> 127 -> 254 entries).
  Sampling therefore differs from a single load. `C19ImmunizationModule.__init__`
  reproduces this: when the Module registry has not been loaded yet, it
  loads it and runs the registry instance's initialize() pass first.
  Constructions after the registry has loaded initialize once, as in Java.
- `C19Vaccine.EUAs` is a Java `TreeMap` (enum-ordinal iteration). The port
  uses a plain dict populated in ordinal order by `initialize()`, which
  preserves the same iteration order for the shot-selector pmf.
- `C19VaccineAgeDistributions.rawDistributions` / `distributions` /
  `firstShotProbByAge` are Java `HashMap`s keyed by `AgeRange`
  (`hashCode = Objects.hash(min, max)`); the port uses `JavaHashMap`, so
  `keySet().stream().filter(...).findFirst()` in `selectShotTime` /
  `chanceOfGettingShot` visits the ranges in the same bucket order.
- `AgeRange` for `Ages_75+_yrs` has `max = Integer.MAX_VALUE` (2147483647),
  reproduced. Its hashCode overflows int32 (negative), as in Java.
- The immunization history map created in `vaccinate` is a Java
  `HashMap<String, List<Long>>`; the port uses `JavaHashMap` for it.
- `C19ImmunizationModule.selectVaccine` falls through to `return null`
  in Java for times that match no branch; with the approval constants
  strictly increasing that path is unreachable. The port returns
  `cast(EUASet, None)` there.
- `inventoryAttributes` raises the shared out-of-scope stub (the
  `helpers/Attributes.java` helper has no owning task in
  docs/port_map.toml), same as the other core modules (e.g. T16).
- Probe design: CovidProbe's process section loads Massachusetts
  providers and the no-insurance payer and gives each person a Boston
  coordinate and yearly no-insurance enrollment, mirroring the runtime
  setup of C19ImmunizationModuleTest, so `vaccinate()` runs end to end
  (encounter, immunization, costs, claim) instead of failing on
  provider lookup. 200 persons, ages 0-99, weekly steps 2020-12-04 to
  2025-12-31: 139 fully vaccinated, 45 never, 16 never eligible,
  274 immunizations in the Java golden.
